# Integrations Overview

NeoPeripheral is designed to seamlessly interface with major mod ecosystems in Minecraft. By acting as an intermediary bridge, it allows ComputerCraft systems to automate complex machinery and read external data streams.

## Supported Ecosystems

- [Create Big Cannons (CBC)](cbc.md): Full control over heavy artillery and cannon mounts.
- [Create & Create Tweaked Controllers (CTC)](create.md): Integration with Linked Controllers and wireless redstone hubs.
