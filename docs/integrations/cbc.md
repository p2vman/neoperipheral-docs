# Create Big Cannons (CBC) Integration

NeoPeripheral integrates with **Create Big Cannons** to allow automated turret control, aiming, and firing via ComputerCraft.

## Supported Blocks

### Cannon Mount
When connected to a standard Cannon Mount, computers wrap it as a `cannon_mount` peripheral.
- [Cannon Mount API Reference](../pheripherals/cannon_mount.md)

### Fixed / Compact Cannon Mount
When connected to a Fixed/Compact Mount, computers wrap it as a `compact_mount` peripheral.
- [Compact Mount API Reference](../pheripherals/compact_mount.md)
