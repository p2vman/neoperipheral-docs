# Create & CTC Integration

NeoPeripheral integrates with **Create** and **Create Tweaked Controllers (CTC)** to bridge wireless Linked Controllers directly with ComputerCraft networks.

## Linked Controller Hub
By placing a **Linked Controller Hub Block**, computers can bind to frequency channels and read button states from handheld Linked Controllers.
