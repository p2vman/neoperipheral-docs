NeoPeripheral

NeoPeripheral is a powerful NeoForge mod that seamlessly bridges ComputerCraft (CC:Tweaked) with advanced in-game systems, physical simulation engines, and popular tech mods.

Core Features

  • Advanced Radar Systems:
  • Radar Block & Creative Radar: Scan for Sable physics sub-levels, retrieving exact coordinates, relative poses, and quaternion orientations.

  • Entity Radar: Detect nearby living entities and players, reporting health, position, and rotation data.

  • Modular Sockets:

  • Expandable peripheral sockets supporting plug-and-play modules (e.g., Radar Module, Creative Radar Module, Crypto Module).

  • NFC Technology:

  • Write, read, and verify NFC Cards using NFC Masters and Readers. Supports raw byte tables, string encoding, and secure B4PIN verification.

  • Sable Physics Engine Integration:

  • Direct integration with the Sable physics engine. Query rigid body mass, center of mass, linear/angular velocity, and apply precise physical impulses directly via Lua scripts.

  • Deep Mod Integrations:

  • Create Big Cannons (CBC): Fully automate Cannon Mounts and Compact Cannon Mounts. Assemble, disassemble, adjust pitch/yaw, and fire autocannons programmatically.
  • Create & CTC: Interact with Linked Controller Hubs to read wireless controller button states across channels.
