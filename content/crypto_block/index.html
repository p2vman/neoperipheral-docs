Crypto Block

Block ID: neoperipheral:crypto
Item ID (Module): neoperipheral:crypto_module
Peripheral Type: neo_crypto

The Crypto Block and Crypto Module represent upcoming cryptographic processing units designed to perform hashing, encryption, and secure key exchanges directly within CC scripts.

[!NOTE]
This feature is currently in active development (Work In Progress).
